# Alimenta+

Sistema de gestão e distribuição alimentar comunitária, desenvolvido como projeto voluntário para o Banco Alimentar Contra a Fome - Centro do Porto.

## Sobre

Plataforma para gestão de doações, estoque, validades, beneficiários e distribuições de alimentos. Desenvolvido como trabalho voluntário, com foco em simplificar o dia a dia de quem gere bancos alimentares.

## Funcionalidades

- Registo e gestão de doações e doadores
- Controlo de inventário e lotes por validade
- Alertas de produtos próximos a vencer
- Gestão de agregados familiares e beneficiários
- Preparação e confirmação de distribuições (cabazes)
- Registo de descartes
- Gestão de utilizadores e permissões

## Tecnologias

- Next.js, TypeScript, Tailwind CSS
- PostgreSQL
- Vitest (testes)
